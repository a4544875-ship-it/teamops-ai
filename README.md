# TeamOps AI 2.0

Carlos 的私人主管工作台：清新大字介面、小熊品牌、照片與動物頭像、案件側邊詳情、快捷進度、主管追蹤、規則提醒及 30 天回收桶。

正式網址：https://a4544875-ship-it.github.io/teamops-ai/

## 使用

正式站以原有 Email／密碼登入。載入私人資料後，每次儲存會自動同步；版本衝突會停止覆蓋並保留本機修改。設定可下載備份、重新載入雲端、登出。照片按儲存才套用，最大 8 MB，會在瀏覽器縮成 320×320 JPEG。

日常 Google Calendar 功能已移除。新版不接收日曆事件、Google 連線設定或日曆對應信箱；舊系統 371 筆事件只保留在原表與私有原始備份，不搬入新版。月底報表另案討論。

## 資料與安全

新版使用 11 張關聯表、owner RLS、複合外鍵與受控 RPC；用 workspace revision 防止跨裝置靜默覆寫。正式資料庫已驗證 owner 讀寫（寫入測試 rollback）、跨帳號／匿名限制、錯誤 revision 拒絕。舊表在切換前核對工作資料，再改唯讀，不刪表、不刪事件。

localhost／下載單檔仍使用隔離示範資料，不會連正式 Supabase。原本瀏覽器舊版儲存空間保留，新版按登入帳號 UUID 分開保存；未同步修改遇到較新雲端不會自動覆蓋。

## 開發與驗證

Node.js 22+：

```sh
npm ci --ignore-scripts
npm test
npm start
```

本機預覽 http://127.0.0.1:4173 ，僅綁定本機。34 項測試涵蓋資料關聯、照片、快捷操作、RLS、交易、正式登入／同步／衝突／登出、僅工作資料遷移與舊表保護。真實帳密與跨實體裝置驗收需由使用者完成。
