# TeamOps AI 2.0 · preview

Carlos 的私人主管工作台。開發分支：`develop/teamops-2.0`。

**隔離測試版本，沒有發布 main／GitHub Pages，也沒有執行正式 Supabase 升級。**

## 開啟預覽

需要 Node.js 22 或以上，網站本身沒有第三方執行期依賴。

```sh
npm start
```

開啟 `http://127.0.0.1:4173`，僅綁定本機。第一次開啟使用虛構示範資料；使用 `teamops_preview_v2` 儲存，不碰舊版 `teamops_offline_v1`。預覽不註冊 service worker。

## 功能

- 奶油白／薄荷綠／柔粉 SaaS 介面、深色主題、手機底部導覽與全螢幕詳情。
- 四種類型、七種統一狀態、兩欄位快速新增、右側概要／進度／追蹤、展開詳情。
- 搜尋篩選、列表／看板、封存、批次優先級／指派、客戶次級管理。
- 進度、案件狀態／下一步／日期、主管追蹤一次儲存；本機失敗不提交部分資料。
- 組員專長／程度、代表色、改名、停用；UUID 保留主要／協助及追蹤關聯。
- 主管追蹤多組員、期限、等待回覆、完成結果、每週／每 30 天重複、完成時回寫進度。
- 五種免費規則：久未更新、等待回覆過久、追蹤到期、無負責人、無下一步；可調整、查看來源、轉追蹤、延後、忽略。
- 全域搜尋、筆記保留原文轉換、JSON 備份／匯入預覽、CSV 案件匯出。
- 30 天回收桶、到期後手動清理；先備份、處理關聯、不碰歷史事件。
- 同分頁概要草稿、離開提示、跨分頁寫入衝突保護、隔離雲端手動同步的版本檢查。

## Google Calendar

日常入口、事件列表、空檔推測與自動同步均不載入。`google-calendar.js` 和舊版 `cloud.js` 留作歷史參考，**新版 HTML／預覽 server／預覽快取均不載入它們**。

371 筆既有正式事件仍在正式工作空間，未複製到公開程式碼。匯入舊 JSON 時逐筆保留 `events` 原文及 `legacyArchive`，不變更 Google。月底同步匯出另案，欄位及格式待討論。

## 安全升級與測試

[隔離升級說明](supabase/V2_UPGRADE.md) · [驗收清單](docs/PREVIEW_ACCEPTANCE.md)

新增 11 張關聯表、RLS、跨擁有者複合外鍵、受控 RPC 寫入、revision 比對、交易、不可變歷史封存。**升級 SQL 只在本機 PostgreSQL 測試，未套用任何雲端專案。** 預覽硬性拒絕正式 Supabase ref；未設定／登入時零外部資料請求。

```sh
npm ci --ignore-scripts
npm test
```

唯一測試依賴 `@electric-sql/pglite` 固定 0.3.14，鎖定檔已保存。23 項自動測試涵蓋本機儲存、371 筆合成事件遷移、RLS、跨帳號外鍵、衝突、回滾、匿名拒絕、歷史不可變及 30 天期限。測試自行模擬 `auth.uid()`，不使用真實公司資料。

真實 Supabase Auth、兩台裝置及正式資料遷移仍待隔離雲端驗證；正式切換另行確認。

## 個人工作台更新

- 品牌、favicon 與空白狀態改成小熊；預設頭像提供小熊、狐狸、熊貓、貓咪、狗狗、水獺。
- Carlos 左側／右上角頭像可開啟照片編輯，組員卡片點頭像也可上傳；可隨時恢復動物。照片按儲存才套用，使用 UUID 保持姓名修改後的關聯。
- 照片只接受 JPG／PNG／WebP（8 MB 內），在瀏覽器裁切、縮成 320×320 JPEG，再隨工作空間保存。沒有照片儲存服務、公開 URL 或自動上傳；照片會包含在私人 JSON 備份與明確觸發的隔離雲端同步。
- 首頁今日／逾期入口、案件旁直接記進度、追蹤一鍵「明天再提醒／等回覆（三天後）／完成」。週期待辦完成僅產生一筆下一期。
- 案件詳情與彈出表單有固定儲存列，顯示已儲存／尚未儲存；刪除後 10 秒內可直接復原，之後仍保留 30 天回收桶。
- 同分頁保留各頁搜尋、篩選、列表／看板、頁面與橫向捲動位置，重新整理也保留。不同分頁獨立保存瀏覽偏好。

23 項測試包含頭像安全格式、備份與改名、快捷操作及重複完成保護。另已瀏覽器實測照片裁切／儲存／重載、動物選擇、快捷進度、三個追蹤快捷按鈕、詳情內立即復原、搜尋記憶與手機固定儲存列。未操作正式站或正式 Supabase。
