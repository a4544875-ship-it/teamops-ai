## 請依序試用

操作只保存在本機預覽；每步可重新整理確認。

- [ ] 首頁：案件、追蹤、組員與提醒的比重、配色與文字是否合用？
- [ ] 新增：只填名稱、選維修，是否立即開啟詳情？
- [ ] 概要：修改狀態／客戶／優先級／多組員／下一步／日期，儲存後重開。
- [ ] 草稿：改名未儲存即關閉，確認提示；重開可還原或捨棄概要草稿。
- [ ] 進度：新增內容並勾建立追蹤，時間軸與追蹤應同時出現。
- [ ] 視圖：列表／看板，測試文字、類型、狀態、組員、客戶、優先級及日期篩選。
- [ ] 批次：勾選兩案件，改優先級／負責人及封存，再顯示封存確認。
- [ ] 組員：新增專長／程度、改名／停用；原關聯完整，新指派預設不顯示停用者。
- [ ] 追蹤：標記多人、設定期限、等待回覆、延後日期、完成結果及同步寫入進度。
- [ ] 重複：每週追蹤完成後只產生一筆下一期，保留完成歷史。
- [ ] 提醒：查看來源、轉追蹤、延後／忽略，重新整理不立即重複相同條件。
- [ ] 規則：改 7 天／3 天、停用／啟用，確認結果變化。
- [ ] 搜尋：用案件內容、組員或進度找資料並開啟來源。
- [ ] 筆記：轉案件／追蹤後原文仍保留。
- [ ] 回收桶：刪除案件使一般清單與統計隱藏，還原後人員、進度、追蹤仍存在。
- [ ] 備份：匯出 JSON、匯入預覽筆數；確認前不取代。CSV 以試算表開啟。
- [ ] 多分頁：A 儲存後 B 再改，應阻止覆蓋並提示重新整理。
- [ ] 手機：底部導覽、列表／看板橫向滑動、全螢幕詳情與儲存。
- [ ] 日曆：首頁、導覽、組員頁無日常日曆，不出現 Google 授權。
